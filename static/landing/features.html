매출 관리

직원(디자이너)별 매출 자동 분리

단말기 결제 시 직원 코드를 입력하면 자동으로 해당 직원의 매출로 귀속됩니다. 코드 없이 결제하면 원장님 매출로 자동 처리됩니다.

1
직원 코드 발급

원장님이 각 직원에게 고유 staff_code를 부여합니다 (가맹점 단위 유니크)

2
결제 시 코드 입력

단말기에서 결제할 때 staff_code를 함께 전송합니다

3
자동 귀속

유효한 코드면 해당 직원 매출, 없으면 원장 매출 + 로그 기록

4
통계 확인

원장님은 직원별 매출을 기간별로 조회하고 비교합니다

정산

정산 & 커미션 자동 계산

PG 수수료, 영업관리자 커미션이 자동으로 계산됩니다. 출금 요청부터 승인까지 시스템으로 깔끔하게 관리하세요.

정산 계산 예시

영업 커미션 (5%)-50,000
순 정산금917,000

광고 분석 대시보드

네이버 플레이스 순위, 블로그 리뷰 수, 방문자 리뷰 수를 기간별로 추적하고 경쟁업체와 비교합니다.

  • 우리 매장 vs 경쟁 매장 비교
  • 날짜별 순위 변동 추적
  • 블로그/방문자 리뷰 수 기록

광고 주문 시스템

블로그 배포, 플레이스 유입 요청을 시스템으로 접수하고 워크플로우로 관리합니다.

블로그 배포 주문

캠페인명, 주소, 키워드, 해시태그, 업체소개, 이미지 링크를 입력하여 블로그 리뷰 작성을 주문합니다.

플레이스 유입 주문

네이버 플레이스명, 검색 키워드(최대 3개)를 입력하여 유입 주문을 접수합니다.
