CORE FEATURES

ADPAY가 제공하는 핵심 기능

오프라인 매장 운영에 필요한 모든 기능을 하나의 플랫폼에서 관리하세요

PG 통합 관리

주요 PG사를 가맹점별로 등록하고 MID/SECRET 암호화 보관. 원클릭 연동 테스트.

  • 가맹점별 PG 설정
  • 민감정보 암호화 보관
  • 실시간 연동 테스트
직원별 매출 분리

직원 코드(staff_code) 기반으로 단말기 결제가 자동으로 해당 직원의 매출로 귀속됩니다.

  • 직원별 고유 코드 부여
  • 자동 매출 귀속 로직
  • 기간별 매출 통계
정산 & 수수료 자동화

결제 누적 데이터를 기반으로 PG 수수료, 영업관리자 커미션을 자동 계산합니다.

  • PG 수수료 자동 계산
  • 영업 커미션 관리
  • 출금요청 워크플로우
광고 분석 대시보드

네이버 플레이스 순위, 블로그/방문자 리뷰 수를 기간별로 추적하고 경쟁업체와 비교 분석.

  • 경쟁업체 비교 분석
  • 기간별 트렌드 추적
  • 순위 변동 알림
광고 주문 시스템

블로그 배포, 플레이스 유입 요청을 시스템으로 접수. 워크플로우로 투명하게 관리.

  • 블로그 배포 주문
  • 플레이스 유입 주문
  • 상태 실시간 추적

자주 묻는 질문

궁금한 점을 빠르게 확인하세요

기존에 사용하시던 카드 단말기를 그대로 사용하실 수 있습니다. ADPAY는 단말기에서 발생하는 결제 데이터를 API로 수신하므로, 별도 하드웨어 구매 없이 바로 시작 가능합니다.

네, 가맹점별로 여러 PG사를 동시에 등록할 수 있습니다. 원하는 PG사를 선택하고, 언제든지 추가/변경/비활성화가 가능합니다.

물론입니다! 직원 코드 없이 결제하면 모든 매출이 원장님 이름으로 자동 기록됩니다. 결제 관리, 정산, 광고 분석 기능은 직원 수와 관계없이 모두 사용 가능합니다.

관리자가 원하는 기간을 선택하면 해당 기간의 총 매출에서 PG 수수료와 영업 커미션을 자동으로 계산합니다. 영업관리자는 커미션을 확인한 후 출금 요청을 보낼 수 있고, 최고관리자가 승인/거절 처리합니다.

현재 MVP에서는 관리자 또는 원장님이 직접 수치를 입력하거나 리포트를 업로드하는 방식입니다. 향후 네이버 공식 API 등 외부 데이터 소스 연동을 위한 인터페이스가 준비되어 있습니다.
